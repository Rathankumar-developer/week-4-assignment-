# Week 4 Capstone Project — Employee Data Analysis

## Overview
This project fulfills **Week 4 (Capstone: Automation / Data Handling)**,
**Option 1 — Employee Data Analysis Project**, from the course outline.
It combines file handling, Pandas, and CSV export into a single working
script.

## Files
| File | Description |
|---|---|
| `employee_analysis.py` | Main script — loads data, runs analysis, exports filtered results |
| `employees.csv` | Input dataset (15 sample employee records: EmployeeID, Name, Department, Salary) |
| `employees_above_threshold.csv` | Output file generated by running the script |

> **Note on the dataset:** The assignment references a Kaggle employee
> dataset. No specific file was provided, so a representative sample
> CSV (`employees.csv`) with the same column structure
> (`EmployeeID, Name, Department, Salary`) is included so the script
> runs end-to-end. Swap in a real Kaggle CSV with the same column names
> to use actual data — no code changes needed.

## What the script does
1. **Load CSV using Pandas** — reads `employees.csv` into a DataFrame.
2. **Calculate average salary** — prints the mean salary across all employees.
3. **Department count** — prints how many employees are in each department.
4. **Filter employees above a salary threshold** — filters and sorts
   employees earning more than `SALARY_THRESHOLD` (default: 60,000).
5. **Export results to a new CSV** — writes the filtered employees to
   `employees_above_threshold.csv`.

## How to run
```bash
pip install pandas
python employee_analysis.py
```
